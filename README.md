<h1 align="center">STORM VUE</h1>

## **О проекте**
STORM VUE — веб-портал, единая панель управления и лаунчер для экосистемы приложений STORM SOFT. Позволяет просматривать каталог утилит, проверять обновления, читать руководства и запускать установленные программы из единого веб-интерфейса.

## **Происхождение и форки**
Оригинальная разработка в составе экосистемы STORM SOFT.

## **Технологический стек**
- **Языки программирования**: TypeScript, Vue.js 3, HTML5, CSS3
- **Фреймворк**: Vue 3 (Composition API), Vite, Pinia, Vue Router
- **Стилизация**: Tailwind CSS, PostCSS, Lucide Vue Icons

## **Ключевые возможности**
- **Каталог утилит STORM**: Быстрый доступ к описаниям, ссылкам на релизы и документации всех проектов.
- **Адаптивный готический и неоновый дизайн**: Оптимизированный интерфейс для десктопных и мобильных экранов.
- **Оффлайн-режим (PWA)**: Возможность установки портала как автономного веб-приложения на рабочий стол.

## **Поддерживаемые платформы и эмуляторы**
- **Операционные системы**: Любая ОС с современным браузером (Windows, Android, Linux, macOS, iOS)

## **Установка и запуск**
1. Откройте онлайн-версию либо скачайте локальный дистрибутив `STORM_VUE_<версия>.zip` из раздела **Releases**.
2. При необходимости установите как PWA через меню браузера.

## **Безопасность и цифровые подписи**
Сборки подписаны сертификатом **CN=STORM SOFT, O=STORM EDEN** (SHA-256 Authenticode).
